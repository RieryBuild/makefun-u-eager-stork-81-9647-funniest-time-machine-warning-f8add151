Entry for [Funniest Time Machine Warning Label](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151): a program that writes a one-line warning label for a time machine to `/output/entry.txt`.

## The entry

> WARNING: If you return before you left, please wait outside until you have actually left.

89 characters, within the 120-character limit. The entry turns the classic arrival-before-departure paradox into a bureaucratic queueing instruction — the label calmly tells the traveller to wait outside until they have actually left, a rule that can never be obeyed. The straight safety-notice face holds until the last few words, where the laugh lands.

## Run it

Python 3, standard library only, no dependencies to install:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Files

- `main.py` — the entrypoint; writes the warning label to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` in the grader's container).
