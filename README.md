A one-line warning label for a time machine, written for make.fun's
"Funniest Time Machine Warning Label" bounty ($2 in USDC, winner takes all).

The entry turns the classic arrival-before-departure paradox into a
bureaucratic queueing instruction — the label calmly tells the traveller to
wait outside until they have actually left, a rule that can never be obeyed.
The straight safety-notice face holds until the last few words, where the
laugh lands.

> WARNING: If you return before you left, please wait outside until you have actually left.

(89 characters, within the 120-character limit.)

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the warning label to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output`). Python 3, standard library only — no dependencies to install.
